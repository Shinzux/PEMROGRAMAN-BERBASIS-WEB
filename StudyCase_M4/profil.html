Tentang Saya

Saya adalah mahasiswa Program Studi Sistem Informasi di Universitas Kebangsaan Republik Indonesia (UKRI). Ketertarikan utama saya berada di titik temu antara bisnis dan teknologi—bagaimana teknologi informasi dapat dimanfaatkan secara nyata untuk menyederhanakan operasional, memecahkan kendala kerja, dan memberikan nilai guna bagi penggunanya.

Dalam belajar dan berkarya, saya memegang prinsip pembelajaran berbasis proyek nyata (project-based learning). Saya terbiasa berpikir sistematis: mulai dari mengidentifikasi masalah di lapangan, memetakan alur kerja data, hingga menerjemahkannya ke dalam bentuk prototipe antarmuka dan kode web yang terstruktur.

Eksplorasi Proyek Nyata

Salah satu proyek yang saat ini sedang saya rancang adalah Sistem Pelacakan Status Servis HP berbasis Web. Ide ini berangkat dari pengamatan terhadap kendala pencatatan manual pada jasa perbaikan telepon genggam, di mana pelanggan kerap mengalami kesulitan mengetahui status perbaikan dan teknisi kesulitan mengelola antrean pengerjaan.

Sistem ini dirancang untuk menyediakan transparansi tahapan pengerjaan (diterima, diagnosa, pengerjaan, hingga siap ambil) serta rekap estimasi biaya perbaikan. Saat ini proyek berada pada tahap perancangan alur proses dan prototipe antarmuka web.
